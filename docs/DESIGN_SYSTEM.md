# Design System

- Nuxt UI components for consistency/accessibility.
- Semantic status colors: success (matched), warning (partial/review), error (unmatched/duplicate), neutral (muted).
- Typography via Nuxt UI defaults; spacing via Tailwind utilities.
- Layouts: UHeader, UMain, UContainer, UCard, UTable.
- Empty/loading/error states handled in pages.
- Status badges should distinguish confirmed vs suggested matches (suggested uses warning + label "Suggested").
