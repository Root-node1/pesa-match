# Hackathon Pitch

30s: PesaMatch helps small Kenyan businesses reconcile payments against orders, resolve exceptions and audit decisions. No payment gateway; works with imported records.

90s: Problem manual reconciliation. Solution deterministic matching + human review + audit + exports. Target: SMEs. Tech: Nuxt 4, NestJS, Postgres, Prisma, Cloudflare, RumptyCloud. Partner: RumptyCloud deployment. Future: live M-Pesa, ThriveWave SMS.
